# 🤖 ESP32 Mecanum Robot

A Wi-Fi controlled robotic vehicle powered by ESP32, featuring four mecanum wheels, a servo-powered lifting mechanism, an ESP32 camera, and a custom mobile application.

✨ Features

* 🚗 4WD mecanum wheel drive
* 📡 Wireless control using ESP32 Wi-Fi
* 📱 Custom mobile application
* 📷 ESP32 camera with web server
* 🔩 Servo-controlled lifting mechanism
* 🎮 Omnidirectional movement
* ⚡ Real-time robot control

🛠️ Technologies

* ESP32
* ESP32-CAM
* Arduino / C++
* Wi-Fi
* Web Server
* Mecanum Drive
* Servo Motor
* Custom Mobile App

📌 Overview

The mobile application communicates with the ESP32 over Wi-Fi to control the robot’s movement and lifting mechanism. A separate ESP32 camera system provides a web-based camera interface for remote visual monitoring.

Built as a personal robotics and embedded-systems project.
